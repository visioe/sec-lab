## 主机与 IP 规划

| 主机名 | 角色 | 系统 | IP（Host-Only） | CPU | 内存 | 磁盘 |
|---|---|---|---|---|---|---|
| kali | 攻击机 | Kali Linux 2026.3 | 192.168.56.10 | 4 | 4096 MB | 40 GB |
| target-ubuntu | 目标/跳板 | Ubuntu 24.04.5 LTS | 192.168.56.20 | 2 | 4096 MB | 40 GB |
| target-win10 | Windows 目标 | Win10/11 企业评估版 | 192.168.56.30 | 4 | 4096 MB | 60 GB |
| target-meta | 经典靶机 | Metasploitable 2 | 192.168.56.40 | 1 | 1024 MB | 20 GB |

每台虚拟机两块网卡：**网卡1 = NAT（出网）**，**网卡2 = Host-Only（互打）**。
> NAT 模式下虚拟机彼此隔离，所以互 ping 必须依赖第二块网卡。

## 复现步骤

1. 装 VirtualBox 7.2.22 + Extension Pack + 7-Zip
2. 下载镜像（Kali 预构建 / Ubuntu 24.04.5 / Metasploitable 2 / Windows 评估版）
3. 建 Host-Only 网卡 `192.168.56.1/24`
4. 建 4 台 VM，各挂双网卡
5. 进客户机执行 `net/` 下对应脚本
6. 验收：`kali → ping 192.168.56.20 / .30 / .40` 全通
